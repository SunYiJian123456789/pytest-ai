# shopping 后端接口清单与用例对照

被测服务：`http://127.0.0.1:8080`，统一响应结构 `{"code": 200, "message": "success", "data": ...}`。
管理端接口由 `AdminAuthInterceptor` 拦截，除登录外均要求 `Authorization: Bearer adm_...`；用户端购物车与支付要求用户 token。

> **覆盖率基准不在这份文件里**：机器可读的清单是 `projects/shopping/data/api_inventory.yaml`，
> 覆盖率由运行期真实请求统计（见 `reports/api_coverage.md`）。这份文件保留接口说明与实测行为，供人阅读。

## 越权（IDOR）实测行为

用户端资源归属全部由服务端从 token 解析，客户端可控的资源 id 只有购物车项 `id`。

| 攻击方式 | 实际响应 | 副作用 |
| --- | --- | --- |
| `PUT /api/cart/{他人项 id}`（改 99 / 改 0 / 改负数） | `HTTP 200` + `code 200` + `success` | 无（SQL 带 `AND user_id`） |
| `DELETE /api/cart/{他人项 id}` | `HTTP 200` + `code 200` + `success` | 无 |
| `GET /api/cart` / `DELETE /api/cart` | 只返回 / 只清空自己的 | 无 |
| `POST /api/pay`（自己车为空） | `code 400` +「购物车为空」 | 不会去结算他人车 |
| `GET /api/pay/records` | 只返回自己的订单（含 `userId`） | 无 |

注意：越权写操作返回 `success` 而不是 403/404——安全上没问题（数据未变），但客户端
无法区分「改成功了」和「这条根本不归你」，属可观测性欠缺，测试据此只断言副作用。

## 已知接口行为（测试据此断言）

1. 登录接口会把 `passwordHash` 置为 `null` 但**仍保留该字段**，因此断言为空值而非字段不存在。
2. 商城商品详情 `/api/products/{id}` 会过滤下架商品；管理端详情 `/api/admin/products/{id}` 不会。
3. `POST /api/upload` 未带 multipart 文件时，Spring 在进入 Controller 前拒绝，返回 500（框架默认错误），
   不是业务码 400；超过 `max-file-size: 10MB` 时同理返回 500（应为 413）。两者均以 `xfail(strict=True)` 登记为缺陷。
4. 未登录访问管理端接口返回 HTTP 401 + `code=401` + 「管理端未登录或登录已过期」。
5. 用户端 token 与管理端 token 双向不可混用。
6. `POST /api/pay` **没有幂等键也没有行锁**：同一购物车被并发支付时，每个请求各自下单。
   实测 3 线程 × 4 轮生成 12 张 SUCCESS 订单（期望 4 张）。串行重复支付则安全（第二次 `code 400`「购物车为空」）。
7. `/api/pay/records` 默认 `limit=8`、最多 50——统计订单数必须显式传 `limit`，否则会被截断误判。
8. 鉴权只认 token，不认来源：篡改 / 乱码 / 超长 / 注入式 token 一律 `code 401` 且 `data` 为空。
9. 上传落盘名一律由服务端生成（`upload-<12 位 hex>.<按 MIME 推导的扩展名>`），客户端文件名（含 `../`）被丢弃；
   扩展名以 MIME 为准，`.txt` 配 `image/png` 会落成 `.png`。
10. 分页参数归一化（`AdminController` 与 `AdminApprovalService` 同一套）：`page < 1` → 1；
    `page > totalPages` → `totalPages`；`pageSize` 夹在 1..100；响应里回显的是**生效后**的值。
    非数字 `page` / `pageSize` → `code 400`。
11. `keyword` 的 LIKE 通配符被转义（`escapeLike`）：`%` 与 `_` 按字面量匹配，不会返回全量。
12. 长度校验只覆盖了部分字段：商品名 >128、副标题 >255 返回 `code 400`；
    **注册用户名 >64、商品描述超出 TEXT(65535 字节) 会直接 500**（无前置校验，撞库异常未处理）。
